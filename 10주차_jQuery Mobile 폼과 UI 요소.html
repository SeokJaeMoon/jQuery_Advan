셀렉트 메뉴 · Select Menu

옵션이 여러 개일 때 공간을 절약하며 하나를 선택하도록 만듭니다.

구현 원리

select + option

  • select: 선택할 목록을 정의
  • option: 실제 선택 항목
  • value: 프로그램에서 사용할 값
기본 예제
<label for="major">전공 선택</label>
<select id="major">
  <option value="AI">인공지능학과</option>
  <option value="SW">소프트웨어학과</option>
  <option value="SEC">정보보호학과</option>
</select>
jQuery Mobile 1.0이 일반 select를 자동으로 모바일형 메뉴로 꾸밉니다.
LIVE DEMO · 학과를 선택하세요
선택 코드: AI
선택 항목이 바뀌면 change 이벤트로 값을 읽습니다.
jQuery 이벤트
$("#majorSelect").bind("change", function(){
  alert($(this).val());
});

플립 스위치 · Flip Switch

ON / OFF처럼 상태가 두 개인 설정 항목을 스마트폰 형태로 제공합니다.

<label for="wifi">Wi-Fi 설정</label>
<select id="wifi" data-role="slider">
  <option value="off">OFF</option>
  <option value="on">ON</option>
</select>

슬라이드 패널 · Panel

모바일 앱의 사이드 메뉴를 화면 밖에서 부드럽게 밀어 넣습니다.

버전 1.0 · 직접 구현

data-role="panel"은 1.3부터 제공됩니다. 1.0에서는 CSS 위치와 jQuery 클릭 이벤트로 대체합니다.

핵심 코드
/* CSS */
#sideMenu { left:-220px; position:absolute; }

/* jQuery 1.6.4 */
$("#open").bind("click", function(){
  $("#sideMenu").animate({left:"0px"},300);
});
패널 열기 → 메뉴 선택 → 닫기 과정을 반복해 보세요.

접이식 아코디언 · Collapsible

제목을 클릭하면 아래의 내용을 펼치거나 접습니다. jQuery Mobile 1.0 기본 지원 기능입니다.

기본 속성
  • data-role="collapsible": 개별 접이식 콘텐츠
  • data-role="collapsible-set": 아코디언 그룹
  • data-collapsed="false": 처음 펼쳐진 상태
예제 코드
<div data-role="collapsible-set">
  <div data-role="collapsible">
    <h3>HTML5</h3>
    <p>웹 구조 작성</p>
  </div>
  <div data-role="collapsible">
    <h3>CSS3</h3>
    <p>디자인과 배치</p>
  </div>
</div>

중앙 팝업 · Popup

대화상자와 오버레이를 사용해 사용자에게 정보를 강조합니다.

버전 1.0 · 직접 구현

data-role="popup"은 1.2부터 사용 가능합니다. 1.0에서는 fadeIn()과 fadeOut()으로 대체합니다.

예제 코드
$("#openPopup").bind("click", function(e){
  e.preventDefault();
  $("#popupBox").fadeIn(180);
});
$("#closePopup").bind("click", function(e){
  e.preventDefault();
  $("#popupBox").fadeOut(180);
});
실제 구현에서는 반투명 배경, 닫기 버튼, 키보드 Esc 처리를 함께 사용합니다.

반응형 테이블 · Responsive Table

화면이 좁으면 데이터의 행을 카드형으로 재배치하여 가독성을 유지합니다.

버전 1.0 · CSS 대체

data-role="table"은 1.3부터 지원됩니다. 1.0에서는 미디어 쿼리 또는 클래스로 배치를 전환합니다.

핵심 스타일
@media(max-width:600px){
  table, tbody, tr, td {display:block;}
  thead {display:none;}
  td:before {content:attr(data-label);}
}
스마트폰에서는 열을 숨기거나 각 행을 세로 카드로 재배치할 수 있습니다.

jQuery Mobile 1.0 호환성 점검

모든 data-role 속성이 모든 버전에서 지원되는 것은 아닙니다.

지원 여부 · 표 1
구성 요소 v1.0 이번 실습
Radio · Checkbox · Select 지원 기본 위젯
Flip · Range · Text / Search 지원 기본 위젯
Collapsible · Grid 지원 기본 위젯
Popup (1.2부터) 미지원 fadeIn/Out
Panel (1.3부터) 미지원 CSS 슬라이드
Table (1.3부터) 미지원 CSS 반응형
실습에서 꼭 기억할 점

코드를 복사하기 전에 버전을 확인하세요.

  • 1.0에서 data-role="panel"만 입력해도 패널은 생성되지 않습니다.
  • 이벤트 바인딩은 jQuery 1.6.4의 .bind()를 사용합니다.
  • 실습용 CDN 주소는 HTTPS로 연결합니다.
현재 jQuery Mobile 1.0은 오래된 교육용 버전으로, 신규 상용 서비스의 기술 선택과 구분해야 합니다.
